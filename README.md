# Игромания — контрольная работа по Web-разработке

Учебный сайт на «классическом» HTML: навигация, закладки, списки, изображения,
таблицы, формы, работа с DOM и JS. Сдано на защиту 21.10.2026.

## Страницы

- `index.html` — главная и общая навигация
- `catalog.html` — каталог: закладки, списки, галерея
- `delivery.html` — доставка и оплата (таблица с фоном)
- `passport.html` — страницы 2–3 паспорта
- `dom_js.html` — DOM_JS: считываем информацию из DOM
- `passport_edit.html` — изменение кириллицы на латиницу по клику
- `algorithm.html` — решение алгоритмической задачи
- `contact.html` — контактные формы
